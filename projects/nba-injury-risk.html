PROJECT

NBA Injury Risk Analysis

An applied statistics project examining factors associated with NBA player injury frequency using injury records and player performance data.

View Code on GitHub ← Back to Projects

OVERVIEW

Project overview

This project investigates factors associated with NBA player injury frequency using injury records and player performance data.

The analysis explores player characteristics, performance measures, workload, and injury patterns using exploratory analysis and statistical modeling.

Tools

R · tidyverse · ggplot2 · broom · Quarto

Focus

Injury frequency · age · minutes played · performance · position

ANALYSIS

What I explored

  • Data cleaning and preparation
  • Injury categorization
  • Exploratory data analysis
  • Visualization of injury patterns
  • Examination of player characteristics
  • Multiple linear regression modeling

CURRENT VERSION

What this project demonstrates

This project demonstrates my ability to combine injury records with player-level performance data and apply statistical methods to a sports analytics question.

The current version provides a foundation that I intend to strengthen as my statistical training develops.

NEXT VERSION

Future improvements

I plan to redo this project within the next year, with a stronger statistical methodology, improved feature engineering, model diagnostics, additional visualizations, and more careful interpretation of injury risk.
